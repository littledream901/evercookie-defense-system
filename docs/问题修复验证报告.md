- 函数参数名仍是 `app_id`, `app_secret`

    set $fangyu_site_key     "{app_id}";      # 参数名与变量名不一致

**建议**：将函数参数改为 `site_key`, `site_secret`

**优先级**：🟠 P1（虽然功能正常，但命名混淆影响可维护性）
