## 🔧 技术亮点

### 1. Composable Hook 模式
```typescript
// 统一状态管理 + 生命周期管理
const { loading, detail, traces, loadTraces } = useAccessLogDetail(props)

// 自动处理：
// - visible 变化监听
// - 数据加载
// - 状态重置
// - 错误处理
// - 请求竞态
```

### 2. 请求竞态处理
```typescript
let loadSeq = 0

async function loadDetail() {
  const seq = ++loadSeq  // 为每个请求分配序号
  try {
    const res = await fetch(...)
    if (seq === loadSeq) {  // 只有最新请求才更新状态
      detail.value = res.data
    }
  }
}
```
**解决问题**：快速切换详情时，先发出的慢请求不会覆盖后发出的快请求

### 3. 懒加载策略
```typescript
// 规则明细仅在需要时加载
function handleTabChange(tabName: string) {
  if (tabName === 'decision' && !tracesLoaded.value) {
    loadTraces()
  }
}
```
**性能提升**：减少不必要的 API 调用

### 4. 计算属性优化
```typescript
// 规则分组计算
const groupedTraces = computed(() => {
  const groups = new Map()
  // 按 rule_id 分组 + 统计
  return Array.from(groups.values())
})
```
**优势**：响应式缓存，数据变化时自动更新
