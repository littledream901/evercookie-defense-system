# 爬虫分析功能开发报告

## 一、功能概述

完成了一个完整的爬虫分析视图模块，提供多维度的爬虫流量分析能力，帮助用户深入了解爬虫访问行为。

## 二、实现内容

### 2.1 后端开发（Python + FastAPI）

#### 2.1.1 数据查询服务层（`access_log_query.py`）

新增 5 个爬虫统计查询方法：

1. **`crawler_overview()`** - 爬虫流量概览
   - 总请求数、爬虫请求数、非爬虫请求数
   - 唯一爬虫数、恶意爬虫请求数
   
2. **`crawler_vendor_distribution()`** - 爬虫厂商分布
   - 按厂商统计请求数、爬虫类型数
   - 各裁决类型统计（hostile/suspicious/clean）
   
3. **`crawler_category_distribution()`** - 爬虫分类分布
   - 按分类统计请求数、爬虫类型数
   - 恶意请求数、平均处理时间
   
4. **`crawler_top_list()`** - 爬虫访问频率 Top 排行
   - 爬虫名称、厂商、分类、请求数
   - 唯一 IP 数、被拦截数、首次/最后访问时间
   
5. **`crawler_timeline()`** - 爬虫流量时间趋势
   - 支持按分钟/小时/天聚合
   - 分爬虫流量和真实用户流量

**文件位置**：`admin-api/src/infrastructure/clickhouse/access_log_query.py`  
**代码量**：新增 145 行

#### 2.1.2 API 路由层（`access_logs.py`）

新增 5 个 REST API 端点：

1. `GET /v2/access-logs/crawler/overview` - 爬虫流量概览
2. `GET /v2/access-logs/crawler/vendor-distribution` - 爬虫厂商分布
3. `GET /v2/access-logs/crawler/category-distribution` - 爬虫分类分布
4. `GET /v2/access-logs/crawler/top-list` - 爬虫访问频率Top排行
5. `GET /v2/access-logs/crawler/timeline` - 爬虫流量时间趋势

**文件位置**：`admin-api/src/interfaces/http/v2/access_logs.py`  
**代码量**：新增 116 行

**公共参数**：
- `siteId`: 站点 ID（可选，不传查全部站点）
- `start`: 开始时间（ISO 8601 格式）
- `end`: 结束时间（ISO 8601 格式）
- `granularity`: 时间粒度（minute/hour/day）
- `limit`: 返回数量限制

## 三、技术架构

### 3.1 数据流向

```
ClickHouse (decision_events 表)
    ↓
AccessLogQueryService (数据聚合查询)
    ↓
FastAPI Router (REST API 端点)
    ↓
前端 API Client (TypeScript)
    ↓
Vue 组件 (数据展示 + 图表渲染)
```

**前端**：
- Vue 3 (Composition API)
- TypeScript
- Element Plus (UI 组件库)

## 六、使用说明

### 6.1 访问路径

- **路由路径**：`/logs/crawler-analytics`
- **菜单位置**：日志管理 → 爬虫分析
- **权限要求**：`analytics.read`

### 6.2 操作步骤

1. 在左侧菜单点击"爬虫分析"进入页面
2. 选择时间范围（默认最近 24 小时）
3. 选择时间粒度（按小时/按天）
4. 点击"刷新"按钮加载数据
5. 查看概览卡片了解整体情况
6. 查看趋势图了解流量变化
7. 查看饼图了解厂商和分类分布
8. 查看 Top 列表了解高频爬虫

### 6.3 典型场景

**场景 1：爬虫流量监控**
- 查看爬虫请求占比
- 分析爬虫流量趋势
- 对比不同时间段的爬虫活跃度

**场景 2：恶意爬虫排查**
- 查看被拦截的爬虫数量
- 分析恶意爬虫来源
- 识别高频恶意爬虫

**场景 3：SEO 健康检查**
- 确认 Google、Bing 等搜索引擎爬虫正常访问
- 查看搜索引擎爬虫访问频率
- 分析是否存在异常拦截

**场景 4：AI 爬虫管理**
- 识别 AI 训练数据爬虫（GPTBot、ClaudeBot 等）
- 统计 AI 爬虫流量占比
- 决策是否需要限制访问
