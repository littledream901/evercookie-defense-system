## ❓ 为什么会有这么多硬编码？

### 1. **历史原因**
- V1 版本是单体巨石函数，所有评分逻辑都写在一起
- V2 重构时保留了原有的评分逻辑，但拆分成了 Scorer
- 注释中明确提到：*"避免 V1 中 1000+ 行 evaluator 巨石"*

### 2. **快速迭代需求**
- 风控规则需要快速调整和测试
- 硬编码在代码中可以快速修改并重启服务
- 避免了配置管理的复杂性

### 3. **业务复杂性**
- 这些评分值是基于**业务经验和数据分析**得出的
- 不同场景下的最优值需要通过 A/B 测试确定
- 频繁变动的配置项如果放数据库，反而增加复杂度

### 4. **设计哲学冲突**
从代码注释看：
```python
# 权重设为 1.0：情报是人工录入的确定性结论，risk_score 已是 0-100 量纲，
# 不需要再放大或衰减。正规爬虫（is_legitimate）不计分，避免搜索引擎被拦。
```

这说明每个评分值都有**明确的业务含义**，不是随意设置的。

---

## ⚠️ 硬编码的问题

### 1. **灵活性差**
- 修改评分需要改代码、重新部署
- 无法针对不同站点使用不同策略
- A/B 测试困难

### 2. **不符合规范**
项目的 `project-rule.md` 明确要求：
> **[SEC-001] 零硬编码**: 所有 Token/密钥统一自 `.env` 读取

虽然这些不是密钥，但配置值也应该遵循外部化原则。

### 3. **维护成本高**
- 业务人员无法直接调整评分
- 需要开发人员介入
- 缺少配置变更历史记录

### 4. **测试困难**
- 单元测试需要覆盖所有硬编码分支
- 无法方便地测试不同配置组合

```python
"""风险评分器配置管理。"""

from __future__ import annotations

import os
from pathlib import Path
from typing import Any

import yaml
from pydantic import BaseModel, Field


class ConnectionTypeConfig(BaseModel):
    datacenter: float = 35.0
    education: float = 5.0
    government: float = 0.0
    mobile: float = 0.0
    residential: float = 0.0
    unknown: float = 10.0


class ProxyConfig(BaseModel):
    tor_score: float = 55.0
    vpn_score: float = 30.0
    proxy_score: float = 25.0
    datacenter_score: float = 30.0
    mobile_discount: float = 0.4


class CrawlerCategoryConfig(BaseModel):
    security: float = 95.0
    library: float = 70.0
    ai_crawler: float = 45.0
    seo: float = 40.0
    archive: float = 30.0
    other: float = 35.0
    feed: float = 10.0
    monitoring: float = 10.0
    social: float = 5.0
    search_engine: float = 0.0


class UserAgentConfig(BaseModel):
    empty_ua: float = 40.0
    unknown_os_browser: float = 30.0
    unknown_browser: float = 15.0
    unknown_device: float = 10.0


class DeviceConfig(BaseModel):
    new_device: float = 25.0
    block_rate_threshold: float = 0.5


class BehaviorConfig(BaseModel):
    method_anomaly: float = 30.0
    long_path_threshold: int = 512
    long_path_score: float = 20.0


class InteractionConfig(BaseModel):
    min_timing_samples: int = 6
    min_mean_interval_ms: float = 250.0
    max_timing_cv: float = 0.05
    no_interaction_span_ms: int = 3000
    min_repeat_keys: int = 8
    repeat_ratio_threshold: float = 0.9
    no_interaction_score: float = 20.0
    regular_timing_score: float = 30.0
    key_repeat_score: float = 12.0


class ScorerWeights(BaseModel):
    ip_reputation: float = 1.2
    proxy: float = 1.5
    user_agent: float = 0.8
    device: float = 1.0
    behavior: float = 1.0
    interaction: float = 0.8
    intel: float = 1.0


class ScorerConfig(BaseModel):
    """风险评分器配置。"""
    
    connection_type: ConnectionTypeConfig = Field(default_factory=ConnectionTypeConfig)
    proxy: ProxyConfig = Field(default_factory=ProxyConfig)
    crawler_category: CrawlerCategoryConfig = Field(default_factory=CrawlerCategoryConfig)
    user_agent: UserAgentConfig = Field(default_factory=UserAgentConfig)
    device: DeviceConfig = Field(default_factory=DeviceConfig)
    behavior: BehaviorConfig = Field(default_factory=BehaviorConfig)
    interaction: InteractionConfig = Field(default_factory=InteractionConfig)
    weights: ScorerWeights = Field(default_factory=ScorerWeights)


def load_scorer_config(config_path: str | None = None) -> ScorerConfig:
    """加载评分器配置。
    
    优先级：
    1. 参数指定的路径
    2. 环境变量 SCORER_CONFIG_PATH
    3. 默认路径 config/scorer_config.yaml
    4. 内置默认值
    """
    if config_path is None:
        config_path = os.getenv("SCORER_CONFIG_PATH")
    
    if config_path is None:
        default_path = Path(__file__).parent.parent.parent.parent / "config" / "scorer_config.yaml"
        if default_path.exists():
            config_path = str(default_path)
    
    if config_path and Path(config_path).exists():
        with open(config_path, "r", encoding="utf-8") as f:
            data = yaml.safe_load(f)
            return ScorerConfig(**data)
    
    # 返回默认配置
    return ScorerConfig()


# 全局配置实例（启动时加载）
_scorer_config: ScorerConfig | None = None


def get_scorer_config() -> ScorerConfig:
    """获取全局评分器配置。"""
    global _scorer_config
    if _scorer_config is None:
        _scorer_config = load_scorer_config()
    return _scorer_config


def reload_scorer_config(config_path: str | None = None) -> ScorerConfig:
    """重新加载配置（用于配置变更后热更新）。"""
    global _scorer_config
    _scorer_config = load_scorer_config(config_path)
    return _scorer_config
```

#### 2.2 配置读取器

```python
class DatabaseScorerConfig:
    """从数据库读取评分器配置。"""
    
    def __init__(self, site_id: int = 0):
        self.site_id = site_id
        self._cache: dict[str, dict[str, float]] = {}
        self._load_config()
    
    async def _load_config(self):
        """加载配置到缓存。"""
        configs = await ScorerConfigModel.filter(
            site_id__in=[0, self.site_id],  # 0=全局，site_id=站点特定
            enabled=True
        ).all()
        
        for config in configs:
            if config.scorer_name not in self._cache:
                self._cache[config.scorer_name] = {}
            self._cache[config.scorer_name][config.config_key] = config.config_value
    
    def get(self, scorer_name: str, config_key: str, default: float) -> float:
        """获取配置值。"""
        return self._cache.get(scorer_name, {}).get(config_key, default)
```
