## 六、部署命令参考

### 首次部署（开发或测试环境）

```bash
# 1. 克隆代码
git clone <repo_url> /opt/fangyu-defense-system
cd /opt/fangyu-defense-system

# 2. 生成生产环境配置
cp .env.production.example .env.production
bash deploy/scripts/gen-secrets.sh  # 自动生成随机凭据并填入

# 3. 修改域名配置
vim .env.production  # 修改 GATEWAY_DOMAIN 和 ADMIN_CORS_ORIGINS

# 4. 执行部署
bash deploy/deploy.sh init
```

### 首次部署（生产环境，从 V2 升级）

如果已有 V2 生产数据，需手动执行 ClickHouse 迁移：

```bash
# 1. 停止 worker（防止迁移期间写入）
docker compose -f deploy/docker-compose.prod.yml stop worker

# 2. 等待 Redis Stream 消费完毕
docker compose -f deploy/docker-compose.prod.yml exec redis redis-cli -a <密码> \
  XLEN fangyu:events:decision

# 3. 备份现有数据（强烈建议）
bash deploy/deploy.sh backup

# 4. 执行 ClickHouse 迁移
docker compose -f deploy/docker-compose.prod.yml exec clickhouse \
  clickhouse-client --multiquery < infrastructure/clickhouse/migration_v7_app_id_to_site_id.sql

# 5. 恢复 worker
docker compose -f deploy/docker-compose.prod.yml start worker
```
